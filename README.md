# Dada Devs Cohort 5: Capstone Template

This is the central submission repo for Dada Devs Cohort 5 capstone projects.
Your project's source code lives in your own fork; this repo holds only the
index of completed projects.

## Submitting your capstone

1. **Fork this repo** and build your capstone inside your fork.
2. **Keep your fork green**: `make test`, `make lint`, and `make fmt-check`
   must pass and test coverage must be ≥ 70%.
3. **Open a pull request** from your fork back to this repo. The PR must
   contain **exactly one change**: a new row added to
   [PROJECTS.md](PROJECTS.md) linking to your fork. Do not include your
   project's source code. That stays in your fork.
4. **Fill out the PR template** checklist in full (it appears automatically
   when you open a PR).
5. A CI check (`check-scope`) will fail your PR automatically if it touches
   any file other than `PROJECTS.md`, so please double-check your diff
   before opening.
6. Once reviewed and merged, your project is listed in
   [PROJECTS.md](PROJECTS.md) for the cohort and the wider community to see.

See [PROJECTS.md](PROJECTS.md) for the current listing and full submission
instructions.
